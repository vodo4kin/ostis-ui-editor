# ostis-ui-editor

Визуальный редактор пользовательских интерфейсов для среды ostis.

- `client` — клиент редактора
- `server` — серверные агенты
- `docs` — каталог компонентов и связей

## Клиент

```bash
cd client
npm install
npm run dev
```

Сборка:

```bash
cd client
npm run build
```

Адрес смотри в выводе Vite.
