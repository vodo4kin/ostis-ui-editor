# ostis-ui-editor

Визуальный редактор пользовательских интерфейсов для среды ostis.

Структура репозитория:

- `client` — React-приложение редактора
- `server` — серверные агенты (пока пусто)
- `docs` — материалы для команды (каталог компонентов и связей)

## Клиент

Нужны Node.js и npm.

```bash
cd client
npm install
npm run dev
```

Сборка:

```bash
cd client
npm run build
```

Открыть в браузере адрес, который выведет Vite.
